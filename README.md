### WP_Moonphase_plugin

Some very old code, which undoubtably needs an update, to display the current moon phase on blog posts and via a sidebar widget.
I know it's sloppy, but all you need to do is drop the "moonie.php" file and the moonimgs directory into your plugin directory, then activate it.

And, mostly, I'm sharing this for people to be able to fork the code for whatever better plugins they want to make from it.
Enjoy!
